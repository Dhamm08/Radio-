# 📻 Radio App

A sleek, lightweight web-based radio streaming application designed for seamless listening to live stations, ambient soundscapes, and online broadcasts.

---

## ✨ Features

- **Live Streaming:** Real-time playback of online radio frequencies and stations.
- **Modern UI:** Clean, responsive, and mobile-friendly audio player interface.
- **Audio Controls:** Volume adjustment, play/pause, station switching, and mute toggles.
- **Lightweight & Fast:** Built with pure web technologies for minimal latency and zero bloat.

---

## 🛠️ Built With

- **HTML5 & CSS3** (Responsive Layout & Modern Styling)
- **JavaScript** (Web Audio API / Stream handling)
